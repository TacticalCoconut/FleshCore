Core Engine Behaviour

Severed pieces, and building bodies before the first hit.

Drop physical severed pieces Forges severed limbs into physics objects. Off, the limb still leaves the body and the target still dies of it; only the object is not made (debris is never affected).
Pre-build nearby NPCs on load Prepares nearby actors on a background thread so the first hit does not have to build them.
Update bodies when equipment changes Automatically refreshes an actor's voxel body when outfits or armour change.
Pre-build all actors seen this session Uses idle background time to prepare every eligible actor seen this session.

Voxel Resolution

Controls the size of each voxel cell. Default (4.0) balances visual detail and performance. Applies to bodies voxelised after the change: a standing lattice keeps the cell it was built with until the body is rebuilt (a load, a Restore, a re-dress).

Cell size Smaller values produce finer cuts but use more memory and CPU.
4.0

Pieces on the Ground

How many cut-off pieces may lie around at once, every body's together, severed limbs included. When a new piece would go past this many, the oldest one is cleared. 0 = no limit: a piece then stays until its own lifetime ends.

Pieces kept Lower keeps long fights tidier and lighter on the frame rate.
35
